# CLAUDE.md — Cosmos

Carnet de recherche en cosmologie mené avec l'user. Index léger : le détail vit dans `carnet/`.

## Règles de travail

- **Faits, tensions, paris : jamais mélangés.** Chaque affirmation dit de quelle catégorie elle relève.
- **Sources récentes obligatoires** (WebSearch + arXiv) avant toute affirmation sur l'état du domaine :
  il bouge chaque année (DESI, Euclid, JWST). Citer avec lien.
- **Un calcul n'est interprété qu'après avoir retrouvé une valeur publiée** (validation de la chaîne).
- **Un pari = une probabilité + ce qui le ferait réviser.** Le réviser se fait par une nouvelle entrée
  datée dans `carnet/paris.md`, jamais en réécrivant l'ancienne.
- Raisonner AVEC l'user : exposer les arguments contraires, y compris contre ses idées et les miennes.
- Français pour le texte, anglais toléré dans les noms de variables. Pas de jargon sans définition.
